**ExactPDF** is a browser extension that saves exactly what you select on a
webpage as a clean PDF — an element, a region, the whole scrolling page, or just
the article text — without the print dialogue and without sending anything off
your machine.

> **Beta, distributed through GitHub.** This is the first public beta. It is
> **not** on the Chrome Web Store; you install it yourself using the browser's
> Developer Mode, as described below. Because it is installed manually, it will
> not update automatically.

## Features

- **Four capture modes**
  - **Select Element** — point at a diagram, table or section and capture just
    that, cropped to its edges. Arrow keys widen or narrow the selection.
  - **Select Region** — drag a box anywhere on screen, then move and resize it
    before capturing.
  - **Full Page** — the whole scrollable page, stitched together, with sticky
    headers appearing once instead of on every screen.
  - **Clean Document** — the article as searchable text with working links,
    without navigation and ads.
- **Two output modes**
  - **Exact** keeps the page looking exactly as it did on screen (an image-based
    PDF; text is not selectable).
  - **Document** produces searchable, cleanly paginated text (styling is
    simplified).
- **Live preview** of the real generated PDF, with page size (Original,
  Continuous, A4, Letter), orientation, margins, background, quality, filename
  and optional metadata.
- **Private by design** — no server, no account, no analytics. Only four
  permissions: `activeTab`, `scripting`, `storage`, `contextMenus`.
- Right-click actions and keyboard shortcuts (`Alt+Shift+E` element,
  `Alt+Shift+R` region).

## Installation

Works in Google Chrome 120 or newer, Brave, Microsoft Edge and other
Chromium-based desktop browsers.

1. Download **`exactpdf-1.0.0-beta.1.zip`** from the Assets below.
2. Unzip it. You should get a folder containing `manifest.json`.
   Keep this folder somewhere permanent — the browser loads the extension from
   it, so deleting or moving it removes the extension.
3. Open the extensions page:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Edge: `edge://extensions`
4. Turn on **Developer mode**.
5. Click **Load unpacked** and choose the unzipped folder.
6. Optionally pin ExactPDF from the toolbar's puzzle-piece menu.

To check the download, compare the ZIP's SHA-256 with the `.sha256` file
attached to this release (`shasum -a 256 exactpdf-1.0.0-beta.1.zip` on macOS or
Linux, `Get-FileHash exactpdf-1.0.0-beta.1.zip` in PowerShell).

**Updating:** download the newer ZIP, replace the contents of the same folder,
then press the reload icon on ExactPDF's card in the extensions page.
**Uninstalling:** press **Remove** on the card, then delete the folder.

## Known limitations

- Browser-internal pages (`chrome://`, the extensions page, parts of the Chrome
  Web Store) cannot be captured — the browser blocks all extensions there.
- Content inside cross-origin frames may not be readable; Select Region still
  works because it captures what is on screen.
- Very long and infinite-scrolling pages are captured up to 60,000 CSS pixels.
- Document mode uses the PDF standard fonts, which cover Latin scripts. Other
  writing systems are preserved by Exact mode instead.
- Canvas and WebGL content has no underlying text, so it is captured visually.
- Virtualised lists that remove off-screen content may be incomplete; the
  preview flags captures whose content did not finish loading.
- Some Chromium browsers may remind you that developer-mode extensions are
  enabled. This is expected for any extension installed outside a store.
