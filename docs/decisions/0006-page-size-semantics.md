# 6. Define what each page size actually means

**Status:** accepted · **Date:** 23 July 2026

## Context

The plan lists four page sizes — Original, Continuous, A4, Letter — without
defining Original versus Continuous, which sound similar. Leaving that ambiguous
would produce two arbitrary behaviours that testing could not adjudicate.

## Decision

| Preset          | Behaviour                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Original**    | The page matches the capture's own size at 96 DPI. It paginates only when the capture exceeds PDF's 14,400 pt (200 inch) limit. |
| **Continuous**  | Exactly one page holding everything, scaled down uniformly if it would otherwise breach the format limit.                       |
| **A4 / Letter** | The capture is fitted to the printable width and sliced down its length across standard sheets, never enlarged beyond 1:1.      |

## Why

- The two presets now answer genuinely different needs. Original means "what I
  selected is what the page is". Continuous means "never break this", which is
  right for feeds and conversations where a page break is an artefact.
- Both behaviours are precisely testable, and are covered by
  `tests/unit/exactLayout.test.ts` and re-verified against generated bytes in
  `tests/integration/pdfRender.test.ts`.

## Consequences

- Continuous can scale a very long capture down noticeably. The preview reports
  the resulting page count and file size so the effect is visible before saving.
- In Document mode, Original has no meaning without a raster, and a 14,000 pt
  page would defeat the purpose of paginated text. There, Continuous means a
  narrow screen-shaped page instead, and Original falls back to A4.
